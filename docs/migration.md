# Legacy migration

Upgraded Swath keeps the v2 configuration and its Pi session references intact. Create or join a network first, then request a preview and explicitly map every member of a multi-folder group to a project/task. Confirming a mapping is the consent to initialize a non-Git folder; files are retained and committed as `Initial import`.

Imports are keyed by `operationId` and can be retried. Originals, unsupported panes, backups, and audit rows remain in SQLite. No import pushes, deletes source folders, or finalizes conflict resolution. Restore `app_config_backups` or export the legacy config if onboarding cannot complete.
